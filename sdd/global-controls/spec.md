# Global controls requirements

## Goal

Align SketchSense theme and language controls with the canonical portfolio header without changing demo navigation.

## Requirements

- Replace permanently visible theme buttons with the canonical compact disclosure.
- Replace the single alternate-language label with the canonical `EN / ES` switch.
- Keep theme before language in the header utility order.
- Preserve theme persistence, live System behavior, localized labels, current subpage, and mobile access.

## Acceptance criteria

- Browser tests cover disclosure selection, language navigation, persistence, and narrow mobile layout.
- The local design mapping records the shared chrome contract.
