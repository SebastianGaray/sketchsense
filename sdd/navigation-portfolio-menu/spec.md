# Navigation portfolio destination

## Requirements

- Show Portfolio as the final destination in the project menu in both languages.
- Do not duplicate the Portfolio destination in the persistent header or footer.
- Preserve every existing project destination and its active state.

- The menu contains six links, including the localized Portfolio destination.
- The header remains usable at desktop and narrow mobile widths.
- Existing navigation, localization, and accessibility checks pass.
